# Proyecto - E-commerce 

**PixelMarket** es una tienda online de imágenes digitales que busca facilitar la exploración, compra y descarga de recursos visuales desde una plataforma web.

El proyecto se desarrolla como una aplicación full stack, con un frontend en Angular, una API REST en Node.js y Express, y una base de datos PostgreSQL administrada mediante Prisma ORM.



## Tecnologías

### Frontend
- Angular
- TypeScript
- HTML y CSS

### Backend
- Node.js
- Express
- TypeScript
- Prisma ORM
- API REST

### Base de datos e infraestructura
- PostgreSQL 17
- Docker y Docker Compose
- Cloudinary para el almacenamiento y la gestión de imágenes

### Herramientas
- Git y GitHub
- Visual Studio Code
- SQLTools
